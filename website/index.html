Question How can a Worker use a Durable Object namespace, stable ID, and stub to send requests for the same entity to one stateful coordinator?

Bind a Durable Object namespace to the Worker, derive a stable Durable Object ID for the entity, obtain that object's stub, and send every request for the same entity to that one coordinator.

Question What is the tradeoff between Workers KV eventual consistency for global configuration and R2 object storage for mutable files?

Use KV for configuration that is read globally and tolerates eventual consistency. Use R2 for mutable file or object content that needs strong read-after-write behavior.

WHAT IT COVERS

Four planes, one inspectable pipeline

Everything maps to one visible architecture and the same project-owned artifacts.

Indexing

  • Document loading, normalization, and metadata
  • Fixed-character, structural, and experimental semantic chunking
  • Local embeddings (MiniLM) and an inspectable NumPy index

Retrieval

  • Live BM25, cosine, and hybrid RRF explanations
  • The same vectors through inspectable NumPy and optional Qdrant
  • Cross-encoder candidate-to-final reranking

Generation

  • Token-budgeted context packing with traceable omitted chunks
  • Grounded prompt assembly and OpenAI-compatible generation
  • Citations and abstention when evidence is insufficient

Evaluation & Observability

  • Browser A/B retrieval evaluation over 16 reviewed questions
  • Answer metrics via LLM-as-judge: faithfulness, relevance, correctness
  • Per-query traces and a curated Failure Lab

A clean CLI interface

The direct, repeatable companion to the visual workspace: index a corpus, retrieve evidence, and ask a question with the same inspectable mechanics.

terminal 
# Build the index from a local corpus
$ rag index --corpus corpus/watsonx-docsqa --chunking-strategy structural

# Retrieve top-5 chunks with hybrid search
$ rag retrieve "What is a deployment space?" --retriever hybrid --top-k 5

# Ask a question and get a grounded answer with citations
$ rag ask "How do I deploy a model?" --context-budget 8192

# Evaluate retrieval quality against a QA set
$ rag eval --qa-file corpus/watsonx-docsqa/qa.jsonl --retriever hybrid

# Diagnose retrieval failure cases
$ rag diagnose --cases-file tests/fixtures/failure/cases.jsonl
